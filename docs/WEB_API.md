# FinPulse interactive demo API

Standalone FastAPI service, port **8011**. Public prefix `/finpulse/`; the proxy strips that prefix. API routes inside the container are `/api/*`. Static frontend is `web/dist`; unknown non-API paths return its `index.html`. No Kafka/Spark processes are started by the demo container. Existing distributed files remain intact.

Every visitor receives `finpulse_session` (HttpOnly, SameSite=Lax, Secure on HTTPS; public cookie path `/finpulse`). Each workspace persists in an isolated SQLite warehouse with a 2-hour sliding expiry. Only synthetic events generated by the original `SyntheticEventGenerator` are accepted. No arbitrary event ingestion, SQL or model-driven financial decisions are exposed.

## Frontend contract

All numbers below illustrate shape; live values come from actual generated records and SQL marts. JSON uses camelCase for UI fields. `raw` event payloads retain the original snake_case contract.

`GET /api/health` → `{status:"ok",mode:"synthetic",storage:"sqlite",version:"2.0.0",engine:"original contracts + quality rules + SQLite"}`.

`GET /api/workspace?country=KEN` returns this complete snapshot. Country is optional; allowed values `KEN`, `UGA`, `GHA`, `TZA`, `ZMB`. All `stats` values stay global; analytics, events, quarantine and product previews/counts are filtered when requested.

`events` contains the latest 250 deliveries, not every event in the warehouse. `GET /api/events?country=KEN&status=accepted&type=gsm_usage&limit=100&offset=0` returns `{events,total,limit,offset}`. Status values: `pending`, `accepted`, `quarantined`, `duplicate`, `replayed`. Late events are **accepted with warnings**, following the original freshness rule. Every delivery has a distinct `id`, including duplicate deliveries of the same canonical `eventId`.

`GET /api/events/:id` accepts a delivery `id` and returns `{event,raw,issues,lineage,related}`. Raw is the immutable received contract; replayed quarantine also includes `{correction,replayEventId}`. Related events share the pseudonymous customer ID, maximum 12.

All successful mutation routes below return the full workspace shape above with an `operation` object. No mutation automatically changes another visitor's workspace.

| Route | Body | Effect / operation |
|---|---|---|
| `POST /api/simulate` | `{scenario:"normal"\|"duplicates"\|"invalid"\|"late",count:20}` | Stages 1–100 synthetic deliveries in bronze; **does not process them**. `operation:{type:"simulation",scenario,count,pending}`. |
| `POST /api/pipeline/run` | `{}` | Executes original Pydantic contract, reusable business rules, event-ID deduplication, original dimensional loader and SQL marts on pending deliveries. `operation:{type:"pipeline",runId,counts}`. Empty queue → 409. |
| `POST /api/quarantine/:id/replay` | `{decision:"approve"}` | Restores only the server-recorded original field value, revalidates, and loads the corrected synthetic event in a transaction. Original bad delivery remains in bronze. `operation:{type:"replay",id,replayEventId,runId}`. Repeat/repaired → 409; missing approval → 400. |
| `POST /api/reset` | `{}` | Replaces only this visitor's sample workspace. `operation:{type:"reset"}`. |

`GET /api/export?dataset=events&country=KEN` downloads formula-safe synthetic CSV. Datasets: `events` (all delivery history), `validated_events` (accepted event facts), `portfolio`, `countries` (currency-labeled market summary), `country_performance` (original country mart schema), and `features` (original customer mart schema); country optional. No cross-currency monetary total is returned anywhere. Mart/fact exports include every bounded row, without a preview/pagination cap. Portfolio and transaction payloads retain currency; original country/customer marts retain country and local-value semantics.

Each product additionally returns `preview` (up to eight actual SQL rows), the full `columns` list obtained from SQLite's schema, and `exportDataset`. Mapping: portfolio→`portfolio`, countries→`country_performance`, features→`features`, events→`validated_events`. These previews retain native snake_case column names. Event history remains a separate delivery-level dataset.

Errors use `{error:"Readable message"}` with 400 invalid input, 404 missing visitor-owned object, 409 conflict/no pending data, 413 oversized body, 429 per-minute/workspace bounds, or 503 capacity. JSON request bodies are required for mutations. Same-origin validation applies behind the proxy. There is no authentication claim: this is a public, isolated synthetic sandbox.

## Execution model

The service imports `EventEnvelope`, `SyntheticEventGenerator`, `validate_business_rules`, `QualityReport`, `LOCAL_SCHEMA` and `LocalPipeline._load_event` from the existing repository. The local pipeline's dimensional loader and mart definitions execute inside each SQLite workspace. The web wrapper adds staged delivery records, bounded visitor sessions, operational traces, known injected corrections, and approval audit. It does not pretend Kafka, Spark, Airflow or AWS are running. Synthetic loan decisions originate in the existing generator and are displayed only as sample analytics; the app does not approve real loans or recommend lending decisions.

## Run and deploy

```bash
python3 -m venv .venv-demo
.venv-demo/bin/pip install -r requirements.demo.txt
PUBLIC_ORIGIN=http://127.0.0.1:5174 PYTHONPATH=src .venv-demo/bin/uvicorn finpulse.demo.main:app --host 127.0.0.1 --port 8011
```

Vite should proxy `/finpulse/api` to `http://127.0.0.1:8011/api`. Set `PUBLIC_ORIGIN` to its exact browser origin (example above uses port5174). Build the static site in `web/`; backend serves `web/dist`. The cookie path defaults to `/finpulse`; direct API tests may set `COOKIE_PATH=/` in a separate test environment.

`docker compose -f compose.demo.yaml up -d --build` uses only the standalone service, a 512 MB limit and persistent SQLite volume. It connects to the existing external network `three-dollar-motel_default` with alias `finpulse-app`; the network must exist. Caddy should use `handle_path /finpulse/* { reverse_proxy finpulse-app:8011 }` and redirect `/finpulse` to `/finpulse/`. The host port is loopback-only. Forwarded headers are trusted inside that private proxy network; do not expose port 8011 publicly. The original `docker-compose.yml` continues to describe the optional distributed reference stack.

Environment: `PUBLIC_ORIGIN` exact HTTPS origin, `FINPULSE_DATA_DIR` writable directory, `FINPULSE_WEB_DIST` built assets, `COOKIE_PATH=/finpulse`. Sessions expire after two hours; maximum 40 concurrent visitor workspaces, 2,500 deliveries per workspace, 100 per simulation, 40 pipeline runs, 100 audit records, 150 requests/40 mutations per minute per session, 10 new sessions/minute/IP. Eight operations can execute simultaneously; requests for the same visitor serialize with a bounded two-second wait. Uncommitted SQLite work rolls back on failure. The app exposes no credentials, arbitrary SQL, uploads, or external AI calls.
